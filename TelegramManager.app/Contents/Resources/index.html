Remote AyuGram

This independent profile stores its history on the VPS. Daily encrypted backups require VPS setup; check the last backup result below. Sign in there yourself. Closing Screen Sharing or this Mac leaves AyuGram running on the VPS. Enable History Sync below to view saved VPS history in your local custom AyuGram. Each device keeps its own login session.

Checking VPS…

Status is checked every 5 minutes while Manager is open and unlocked, and when you return after a missed check. Alerts appear below the toolbar. Low space means less than 2 GB or 10% free. Process status does not confirm Telegram login or message delivery.

History Sync · VPS → Local

Sync saved deleted text and edit history every 5 minutes while Manager is open and unlocked, and before opening local AyuGram. The local client must be closed; it is never closed for you. Sessions, settings and local read markers stay separate.

Choose a profile, then check the local and VPS archive IDs.

History sync is off until you enable a profile.

Only existing, initialized custom AyuGram profiles are supported. Media files and unsaved messages are not transferred. One private archive-only recovery copy is kept before each changed import. Local content wins conflicts; ambiguous edit ordering is reported.

Manager, Telegram and AyuGram Updates

Weekly checks fetch release information only. Downloads require your button click. Official client updates install separately.

Manager and Custom AyuGram

Download and Schedule queues one update at a time. Quit Manager AND all Telegram/AyuGram clients normally before installation. Nothing is force-closed or automatically relaunched.

Transfer to Another Mac

    
Transfer selected AyuGram text history, supported settings, and Manager organization. Files contain private message text and notes. No authorization, sessions, cache, media, VPS credentials, or local-read markers are included.
On the destination Mac, use New account to choose target folders, log in independently, initialize AyuGram, and close it before importing history. This tool never opens, closes, or logs in to an account.

    

      

        
        
        
      

      
Text history merges keep local values on conflicts; unsupported media or reply payloads fail export without changing the source. Supported settings use source values: deleted/edit history saving, global ghost mode, translation provider, peer IDs, and semitransparent deleted messages. Organization fills blank fields and merges pins and workspaces without moving or renaming accounts. A fresh initialized history database requires an explicit numeric ID and same-account confirmation. Bulk imports may partially finish; retrying is safe.
